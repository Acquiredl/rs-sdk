# acquiredl

This is my bot on rs-sdk. Claude Code plays it through the SDK's MCP server, and loxodonta, my receipt-chain recorder, writes one receipt per move from outside the game process.

I like RuneScape, and this is a fun way to grow loxodonta. A game is a different kind of agent run than a coding session: long loops, the same call repeated hundreds of times, and other players' chat as a live prompt-injection surface. The aim is runs whose timeline anyone can verify with one file, and to share what I find here and upstream.

What's in this folder: `script.ts` is the current grind script, `lab_log.md` holds the session notes, and receipt packages of real runs will land here once there are some. `bot.env` holds the credentials and stays out of git.

Status: set up on 2026-10-19, no run yet. Questions and ideas are welcome, open an issue.
